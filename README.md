# Susidlc World

A static, English-language creative world built with HTML, CSS, and JavaScript. Music, Art, Fashion, and Faith share one visual identity centered on Susidlc’s original red doll artwork.

## Preview

Run `python3 -m http.server 4173 --bind 127.0.0.1` in the repository and open http://127.0.0.1:4173. No package installation or build step is required.

## Visual direction

Only the original red doll painting and its supplied close-up are rendered as images. Studio, interior, piano, and other reference photographs are not shipped. The gallery walls, warm light, record sleeves, shadows, and material studies are HTML/CSS. The original artwork is not generatively altered. The favicon embeds the supplied face detail, framed through an SVG viewBox.

Daylight / Lamplight changes the atmosphere; the preference is stored only in the visitor’s browser. Motion honors reduced-motion preferences.

## Content and links

Edit `assets/content.js` to update the email, Spotify, albums, YouTube, Daily Bread channels, or verified audiobook links. Album links use typographic artwork rather than album photographs. Spotify opens externally, keeping non-doll imagery out of the site. A no-JavaScript visitor can still use the artist link, YouTube, navigation, and email.

Art separates original work from future AI transformations. The full painting and detail are two views of the same artwork. No AI versions are claimed. Fashion remains a collection in progress, with no store or checkout. Shopify is reserved for a later phase. Audiobook links are still pending.

## Hosting

GitHub Pages and the existing `CNAME` (`susidlc.com`) remain unchanged. Work is on the local `design/susidlc-world` branch. Do not publish or merge into the publishing branch before the owner approves the revised preview.
