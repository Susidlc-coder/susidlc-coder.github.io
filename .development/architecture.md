# Architecture

Public routes: index.html, music.html, art.html, fashion.html, faith.html. Shared presentation: assets/style.css and assets/app.js. Owner-provided content links: assets/content.js. No build system, backend, or hosting changes.

Tracking Systems stays outside the public experience. No page, nav link, card, or public module is enabled. Its earlier content is retained in Git history. A future route can reuse .page-intro, .wrap, header, footer, and shared assets only after an explicit request.

Shopify has a reserved shopUrl field. A future HTTPS store link can be added without changing GitHub Pages, CNAME, or exposing secret credentials.

All site UI, navigation, accessibility names, status copy, and metadata are English. Original release names and external account URLs are proper names.

Only doll-original.webp, doll-detail.webp, and the favicon are permitted image assets. These originate from IMG_7554.png and IMG_7782.png. Resize/encoding and UI framing preserve the original painted image. No generative redrawing or AI artwork is used.

The original interior and album images were removed from the current checkout. Git history preserves the earlier design. The OG preview uses the original doll artwork, replacing the studio photograph.

The user has not approved publishing. Remote authentication was unavailable in the previous pass. No remote writes are part of this revision.
